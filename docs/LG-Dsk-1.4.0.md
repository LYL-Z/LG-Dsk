## 来源边界

- 本地 Git 基线：GlassDesk 公开源码快照 `v1.3.1`，仓库提交 `c825c9dad718f22900b24b255f73ddb4989d347d`。
- 上游源码仓库：[everlosttime/glassdesk-open-source](https://github.com/everlosttime/glassdesk-open-source)。截至本次移植，公开源码只到 1.3.1。
- 1.3.6 与 1.4.0 的公开说明：[1.3.6 说明](https://github.com/everlosttime/glassdesk-updates/blob/main/Release-notes-v1.3.6.md)、[1.4.0 说明](https://github.com/everlosttime/glassdesk-updates/blob/main/Release-notes-v1.4.0.md)。更新仓库只有安装包、说明和校验文件，没有 1.4.0 源码。

## 品牌和外观

- 保留原来的深色液态玻璃材质、圆角、布局和窗口层级。
- 图标把 Z 替换为浮雕 LG 字标，增加少量陶土橙放射元素。这是用户桌面风格启发的衍生创作，不使用 Claude 字标或官方图形。
- 产品元数据、设置窗口标题、Dock/启动台标题、托盘提示和图标改为 LG Dsk。为避免扩大重命名范围，技术命名空间、程序集名称、部分内部存储/兼容路径仍保留 GlassDesk。
- 版本属性设为 1.4.0；不把上游 1.4.0 私有源代码写成已获得。

## Lenovo Legion RTX 5090 适配边界

用户提供的显示器截图为 3840×2400、240 Hz、10 位 SDR。基线已经使用每显示器 DPI 感知和高质量玻璃渲染。本次保持 16 ms 活跃动画帧间隔、静止时 100 ms 轮询，并复用原玻璃窗口承载切换条；没有为了 240 Hz 增加后台轮询或全屏纹理。

这次完成的是代码与测试检查，没有在该 Legion 笔记本上启动完整程序、切换真实窗口或观察游戏/全屏应用，因此 GPU 占用、多屏/HDR、240 Hz 真实帧率和长时间运行效果仍未现场核验。

## 本地数据和构建

- 应用数据仍由现有 `AppPaths.ForCurrentUser()` 决定。源码运行时使用 `AppContext.BaseDirectory\Data`；不会自动导入另一安装目录的数据。
- 当前变更没有安装到 Windows，也没有创建发布安装包或推送 GitHub。
- `GlassDesk.exe` 程序集文件名保留，以减少对现有资源 URI、安装身份和内部引用的改动；Windows 文件属性与应用界面显示 LG Dsk。
- 公开源码仓库缺少 `build/package.ps1` 与 `build/verify-package.ps1`。当前验证以应用编译和可运行测试项目为准，不声称安装包构建通过。
