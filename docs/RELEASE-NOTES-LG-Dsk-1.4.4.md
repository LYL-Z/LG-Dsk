# LG Dsk 1.4.4

1.4.4 是面向 1.4.3 用户的维护版本。保留液态玻璃 Dock 与启动台、暖色 Claude 衍生设置界面及既有布局，重点改进更新中断恢复、Windows 自动隐藏任务栏下的应用切换、玻璃首帧回退与显示桌面后的 Dock 定位。

## 变更

- **断点续传与重试：**更新检查对短时网络失败有限重试；安装包下载最多自动重试 6 次，并支持 HTTP Range 续传。临时文件按版本与 SHA-256 区分，网络中断或用户取消时保留有效下载部分，重试可从已有字节继续。安装包下载完成后仍需匹配发布元数据中的大小和 SHA-256；内容或续传协议校验失败时会删除临时包。完全断网、发布源不可用或所有连接长期失败时，客户端无法保证完成下载，但可以在网络恢复后重新尝试。
- **自动隐藏任务栏应用岛：**设置启用且 Windows 任务栏自动隐藏、外部应用处于前台时，应用岛出现在屏幕上方中央；不再要求前台窗口先被判定为全屏。鼠标移入紧凑岛后展开应用清单，离开后自动收起；全局快捷键仍可显式打开并保持完整切换条。
- **扩展应用清单：**展开视图包括 Dock 固定应用、可见或最小化窗口、应用库可匹配的后台进程，以及 Windows UI Automation 可访问的通知区域项目。固定应用可启动或切换，窗口项可切换；无窗口后台进程和托盘条目用于查看状态，不承诺可直接激活。
- **托盘读取边界：**Windows 没有受支持的公开接口用来枚举任意第三方托盘图标。本版本仅尝试读取辅助功能树暴露的通知区域项目；未暴露给 UI Automation 的图标可能不显示。此能力不替代 Windows 通知区域，也不模拟任意托盘点击。
- **降低黑闪与桌面宠物残影：**Dock 和启动台的安全回退使用暖色不透明面；启动台关闭后及文件选择等系统模态对话框返回后，清除旧捕获并重新采集桌面。可用捕获准备完成时仍使用原液态玻璃渲染；回退色不代表玻璃捕获已成功。
- **修复 Show Desktop 后 Dock 重叠：**执行“显示桌面”后，在 Windows Shell 更新工作区时重新读取主显示器几何，并按任务栏边缘避开与工作区重叠的任务栏区域，避免 Dock 与系统任务栏重合。无需重启应用即可刷新位置。
- **兼容性：**保留 GlassDesk 内部程序集、数据目录、单实例身份和安装 AppId，用户数据格式与安装身份不随品牌改名。

## 安装资产

- `LG-Dsk-1.4.4-win-x64-Setup.exe`：Windows x64 用户级安装包。
- `LG-Dsk-1.4.4-win-x64.zip`：自包含便携版，运行 `LGDsk.exe`。
- `SHA256SUMS.json`：发布资产与构建清单的 SHA-256 和文件长度。

安装前建议从设置页创建用户数据备份。安装程序不会自动启用登录启动。便携版与安装版的数据位置相互独立。

## 使用边界

- 更新器通过 GitHub 正式发布源下载，没有配置镜像站。自动重试和断点续传能够改善可恢复的连接中断，但无法让没有网络路由或持续不可达的发布源变得可用。
- 应用岛由普通桌面窗口实现；部分独占全屏、受保护画面或系统安全桌面可覆盖它。此时继续使用 Windows `Alt+Tab`。
- 托盘项目是否可见取决于 Windows 当前版本及辅助功能树的暴露情况。任务栏隐藏溢出区或应用自绘菜单可能无法可靠读取。
- 回退色为捕获不可用时的保护画面，不是“液态玻璃已加载”的证明。显卡驱动、DWM 策略或第三方桌宠宿主仍可能影响实机画面。
