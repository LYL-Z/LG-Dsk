# LG Dsk 1.6.0 本地候选说明

**状态：本地候选，尚未发布。**本版本以公开的 1.5.0 提交 `b6751d05e109ffb68868cfd14aa7b7a8d8853095` 为基线。GitHub 上的公开 Release 和更新目录不会因本地构建而改变。

## 改动摘要

- Dock 保留原有 `LiquidGlassSurface` 和单一玻璃背板；呈现策略区分桌面、普通应用、任务栏自动隐藏和已知独占全屏状态，Shell 工作区、显示器及 DPI 变化会触发延迟重定位。
- 便携副本按所在目录隔离单实例身份和 `Data`，可与安装版分别运行；安装版继续沿用原兼容身份与数据迁移路径。
- 调整应用岛与切换器：被动信息在已知独占全屏时收起；显式快捷键切换仍可显示。活动反馈按优先级协调，倒计时使用单调时钟，并增加系统音量和电源状态显示。
- 启动台支持一次选择多个快捷方式，并补充磁贴方向键、Enter、Esc 与焦点反馈；应用启动、分组和窗口内容仍由现有分层服务管理。
- 增加 Finder、设置、下载和废纸篓的独立前景图像入口；暖色设置界面保留主题、高对比度、透明度和减少动画偏好。上述图像不是 Apple 官方素材，配色不是 Anthropic 官方主题。
- 托盘图标在 Explorer 通知区域重建后重新注册；启动项状态会区分本产品、另一份已知安装、过期路径和无关程序，避免覆盖不属于本产品的启动项。
- 安装版首次启动可把旧程序目录旁的 `Data` 复制到用户数据目录，逐文件校验 SHA-256，并在冲突、重解析点或旧实例占用时停止；旧副本保留作回滚。备份恢复新增事务暂存和路径安全检查。
- 更新链支持验签的静态目录、分块 SHA-256、并行传输、断点续传、重试和 GitHub 备用源。更新安装包仍要求用户确认。此次候选没有部署到静态更新站点。
- 新增固定提交 SHA 的 Windows CI 工作流。配置已经写入本地分支，尚未推送，因此没有远端 Actions 运行结果。

## 版本和兼容

- 产品版本：`1.6.0`；文件版本：`1.6.0.0`。
- 程序集版本 `0.2.2.0`、`GlassDesk.Independent` 安装身份和现有用户数据格式保持兼容。
- 目标为 Windows 11 x64（Build 22000 及以上），.NET 10 自包含发布。项目不新增付费服务或运行时依赖。
- 本地安装包未进行 Authenticode 签名。SHA-256 清单能检查文件完整性，不能证明发布者身份。

- 目标 Windows 设备上的 Dock/应用岛视觉、刷新率、HDR、混合 DPI、多显示器和 GPU 捕获表现。
- Windows 任务栏自动隐藏切换、Explorer 实际重启、独占全屏、快速显隐、睡眠/唤醒、宠物遮挡及长时间运行。
- 对真实 1.5.0 安装进行升级和回滚；本地安装器尚未实际安装到用户配置。
- 各地区更新源可达性。签名和哈希验证不能推出网络在中国大陆或全球均可达。
- 独立渗透测试、完整静态安全审计、SBOM 发布、覆盖率测量和用户桌面交互验收。
- 修订后的 Dock 几何测试，以及完整 Dock 测试集和原生捕获恢复用例。
