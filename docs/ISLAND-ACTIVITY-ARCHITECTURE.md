# LG Dsk 应用岛活动架构

本文记录 LG Dsk 1.5.0 对现有自动隐藏任务栏应用岛的增量设计。它沿用当前 .NET 10、WPF、Win32 和 Inno Setup 用户级安装结构；不新建 IslandBridge 程序、不迁移用户数据、不更换安装身份，也不改造原液态玻璃 Dock 与启动台。

## 可行性与能力边界

| 能力 | Windows 接口/现有实现 | 权限与前提 | 当前边界 |
| --- | --- | --- | --- |
| 自动隐藏任务栏时的应用岛 | 现有 WPF Dock 窗口、Win32 窗口/前台状态、任务栏工作区判断 | 普通用户；遵循系统窗口管理 | 用户态浮层可能被独占全屏、安全桌面或受保护窗口覆盖 |
| 应用和窗口切换 | 现有窗口清单、应用库匹配、窗口激活；后台项只能展示 | 普通用户；受系统完整性级别限制 | 没有窗口的后台进程不可激活；系统或高权限窗口可能不可枚举 |
| 托盘项目 | Windows UI Automation 暴露的辅助功能树 | 普通用户；目标程序需暴露可访问信息 | 不是完整 Shell 通知区域 API；未暴露或虚拟化的图标可能缺失/不可操作 |
| 默认播放端点音量变化 | Core Audio `IAudioEndpointVolume` 与设备通知回调 | 普通用户；默认渲染端点需可用 | 只读主音量/静音；不提供逐应用混音，也不保证厂商硬件音量旋钮可见 |
| 电池和供电状态 | Win32 `GetSystemPowerStatus` 与 `PowerModeChanged` | 普通用户；由系统提供值 | 无电池、未知和 API 失败分别表达；不推断剩余续航 |
| 快捷倒计时 | `TimeProvider` 单调时间戳 + WPF DispatcherTimer 展示刷新 | 无额外权限 | 当前进程内有效；退出、重启及休眠期间不承诺后台闹钟 |
| 媒体会话 | WinRT `GlobalSystemMediaTransportControlsSessionManager` | 需要应用包能力 `globalMediaControl`；当前为 Inno Setup 未打包程序 | 本版本暂不访问/控制其他应用媒体会话；不伪造媒体数据 |
| 跨应用通知 | `UserNotificationListener` | 需要应用包能力、包身份及用户授权 | 当前安装形态不具备这些条件，未接入通知读取 |
| 蓝牙、亮度、下载与插件 | 依设备接口、数据源、包身份或明确授权而定 | 按具体 API 能力检测 | 当前未实现，不显示演示数据冒充真实事件 |

这张表区分 Windows 提供的能力、应用当前实现和未接入的可选能力。用户态 WPF 浮层不是 Windows Shell 组件，也不拥有 iOS/HarmonyOS 系统级活动权限。

## 边界与运行模型

应用岛继续由现有 Dock 窗口承载。当 Windows 任务栏启用自动隐藏、外部应用位于前台且设置允许显示时，LG Dsk 显示屏幕上沿中央的紧凑岛；悬停进入展开应用清单，单击固定展开，再次单击或关闭可收起。全屏切换条仍可通过既有快捷键打开。岛不是 Windows Shell 扩展，独占全屏、安全桌面和受保护窗口可以覆盖它。

`AppIslandStateMachine` 只拥有可见性、悬停和固定展开状态；WPF 窗口依状态渲染，不从动画尺寸反推逻辑状态。系统活动另由 `IslandActivityCoordinator` 管理，因此音量或计时提醒不直接重设窗口尺寸，也不会销毁正在显示的应用清单。

## 活动仲裁

活动由稳定键、文本和整数优先级标识。永久活动（例如正在运行的计时器）可被更高优先级的短时事件覆盖；同键事件更新现有项目并续期，而不是重复堆叠。事件过期后，界面回到仍有效的最高优先级活动。过期时间使用 `TimeProvider` 单调时间戳，避免系统时钟校准改变短时显示或倒计时。

当前优先级约定：

| 活动 | 优先级 | 生命周期 |
| --- | ---: | --- |
| 计时器运行摘要 | 30 | 计时器存在期间 |
| 默认输出音量/静音变化 | 50 | 最后一次变化后 2.4 秒 |
| 一个或多个计时器完成 | 100 | 6 秒 |

这些值是当前产品内的排序约定，不是 Windows 系统通知优先级。

## 本机活动来源

### 音量

`CoreAudioEndpointMonitor` 在独立 MTA 工作线程上绑定当前默认多媒体播放端点。`IAudioEndpointVolume` 提供初始音量和静音状态，控制变化通知负责后续更新；设备拓扑通知触发重新枚举，以适应默认扬声器、耳机和蓝牙端点切换。Core Audio 回调只解析通知、通过 `Interlocked.Exchange` 保存最新快照并设置信号，不等待锁、不调用 UI、不在回调中注销或释放 COM 对象。COM 注册、注销和释放均由拥有该对象的工作线程执行。

此功能只读取系统主播放端点，不控制音量，不读取每个应用的独立音量。没有默认端点时将活动标记为不可用；不能保证能看到绕过 Windows 软件音量控制的硬件专有变化。退出期间若 COM 清理超过短等待窗口，信号句柄留给工作线程在退出路径释放，避免工作线程访问已销毁的等待对象。

### 电源

`GetSystemPowerStatus` 是只读聚合信息源，并由 `PowerModeChanged` 与低频刷新共同更新 UI。电量未知、无系统电池和调用失败分别保留，不把未知编码解释成台式机。仅当 Windows 给出可用百分比时显示电量，不从设备型号或历史值推断。

### 计时器

应用岛展开视图提供 5、15、25 和 45 分钟快捷倒计时，可同时创建最多 8 个；全部暂停、继续或清除。剩余时间由单调时钟差值计算，DispatcherTimer 每秒只刷新显示。完成事件进入同一优先级仲裁器，可覆盖音量/计时摘要，6 秒后恢复尚未结束的活动。

本版本倒计时只存在于 LG Dsk 当前进程内，退出或重启应用后不会恢复；它不是闹钟服务，也不会在 LG Dsk 退出时继续触发。跨重启恢复、用户自定义时长/名称和后台可靠提醒需要独立持久化与通知生命周期设计，当前不宣称已实现。

## 应用清单一致性

窗口、应用库匹配后台进程、固定应用和可访问的通知区域项目先聚合为完整快照，再由 `ObservableRangeCollection.ReplaceAll` 发出单个 Reset 通知。扫描重入时只保留一个待执行刷新；扫描暂时失败时保留最后一份完整清单，避免清空、逐条重排和闪烁。

托盘项目依赖 Windows UI Automation 暴露的信息，不能枚举或激活所有第三方托盘图标。后台进程只有被本机应用库识别时才纳入，也不保证无窗口进程可切换。

## 架构决策记录

### ADR-1：在现有 Dock 窗口中承载应用岛

- **问题：**新建独立浮层或迁移到新的桌面框架，可能与已交付的玻璃材质、输入行为、应用身份和用户数据发生冲突。
- **备选：**复用 WPF Dock 窗口；新增独立 WPF 窗口；迁移为 WinUI/MSIX 应用。
- **决定：**复用现有 WPF Dock 与其呈现策略，只增加应用岛状态和活动数据。
- **影响：**保留安装、单实例和数据兼容性；用户态覆盖全屏的限制仍在，MSIX 专属 API 不因此可用。

### ADR-2：业务活动与窗口可见状态分开仲裁

- **问题：**若音量或计时事件直接操作主窗口尺寸/显示状态，容易打断应用清单、造成动画竞争和黑闪。
- **备选：**每种活动各自控制窗口；单一优先级活动协调器与独立应用岛状态机。
- **决定：**活动只产生数据，`IslandActivityCoordinator` 排序和恢复；`AppIslandStateMachine` 管窗口呈现。倒计时使用单调时间戳。
- **影响：**短时反馈可覆盖并恢复低优先级活动；计时准确性不依赖 UI 帧率，但当前不跨进程持久化。

### ADR-3：Core Audio 回调只入队，COM 生命周期归属 MTA 线程

- **问题：**在 Core Audio 回调中等待 UI、注销接口或释放 COM 对象会增加重入、卡顿和释放竞态风险。
- **备选：**UI 线程直接轮询；回调内更新 UI；由 MTA 所有者线程管理 COM 并传递合并后的快照。
- **决定：**采用 MTA 所有者线程；回调仅保存最新值并发出信号，UI 使用 Dispatcher 异步处理活动。
- **影响：**音量变化通过事件驱动，设备拓扑变化时重新连接；真实扬声器/蓝牙热切换仍需硬件验收。

### ADR-4：本版本保留 Inno Setup 用户级桌面包

- **问题：**媒体会话和通知监听要求的包能力与当前未打包安装形态不匹配；直接迁移会改变部署、升级及兼容面。
- **备选：**保持现有安装形态并延后这些 API；立即迁移 MSIX 并验证能力/用户授权。
- **决定：**保留现有 Inno Setup 安装身份，不把无权限的能力伪装为已实现。
- **影响：**当前可继续自包含安装和便携 ZIP；媒体/通知功能需要后续单独的打包设计和目标设备验证。

## 兼容性与延后项

本版本保留可自包含分发的桌面 WPF 程序和现有安装包，不为新增功能改成 MSIX。Windows 媒体会话 API 在微软文档中声明 `globalMediaControl` 应用能力；当前安装形态没有该包能力声明，因此系统媒体会话发现/控制暂不接入。通知监听、任意托盘点击、文件传输活动、亮度/蓝牙状态和跨进程插件也不在本版本中伪装为可用。

当前测试覆盖纯状态转换、活动同键合并/优先级回退、单调计时、暂停续计、电源编码和音量标签格式。编译及自动化测试无法替代真实 Windows 音频设备切换、扬声器/蓝牙热插拔、任务栏自动隐藏、多屏 DPI、Clawd 桌宠遮挡、独占全屏或 RTX 5090 面板验收。
