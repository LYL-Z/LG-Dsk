# LG Dsk 1.4.3

1.4.3 是面向 1.4.2 用户的维护版本。它保留原有液态玻璃 Dock、启动台布局、暖色 Claude 衍生设置界面与主要交互，集中修复快捷方式批量导入、遗留自启动路径和窗口重新显示时的桌面材质问题。

## 变更

- **批量添加应用与快捷方式：**“添加”菜单明确支持一次选择多个文件、程序或 Windows `.lnk` 快捷方式。文件对话框不再自动解引用快捷方式，而是把快捷方式文件本身交给既有解析器，避免 Shell 对话框错误地打开目标程序；导入服务按条目报告结果，单条损坏不会中断整个批次。
- **恢复自启动设置：**如果当前用户 `Run` 项精确指向已经不存在、但其父安装目录仍存在的 `GlassDesk.exe` 或 `LGDsk.exe`，设置页会标明旧路径并允许用户主动替换为当前 LG Dsk。其他路径、参数、缺失目录、不可访问路径及非字符串注册值仍受保护，不会被自动覆盖。
- **清理用户可见品牌残留：**排序保存失败提示、旧实例提示和全屏检测提示使用 LG Dsk 文案。程序集、数据目录、窗口身份、备份格式与安装 AppId 等兼容标识保持不变。
- **防止隐藏期间的宠物残影：**每次 Dock 或启动台重新展开前，清除隐藏窗口缓存的桌面纹理并采集当前桌面。该刷新不依赖窗口列表是否变化，因此桌面宠物移动或消失时不会继续复用旧捕获；若采集失败，使用安全的暖色不透明过渡面等待新材质，不延长旧画面的显示时间。
- **降低每次打开窗口时的黑闪：**液态玻璃捕获尚未准备好时，不再先绘制近乎透明的深色等待层。采集成功后仍使用原有液态玻璃渲染；捕获不可用时显示暖色不透明兼容面，不伪装成已获得玻璃材质。
- **保持定制边界：**未重做 Dock、启动台或设置结构；继续使用液态玻璃视觉与 1.4.2 的暖色设置主题。内部 `GlassDesk` 命名空间和安装身份继续保留，用于兼容历史数据及升级。

## 安装资产

- `LG-Dsk-1.4.3-win-x64-Setup.exe`：Windows x64 用户级安装包。
- `LG-Dsk-1.4.3-win-x64.zip`：自包含便携版，运行 `LGDsk.exe`。
- `SHA256SUMS.json`：安装包、便携 ZIP、构建报告及清单文件的 SHA-256 与字节长度。

安装前建议从设置页创建一次用户数据备份。安装器不会自动启用登录启动；如需使用，请在设置页勾选“登录时启动 LG Dsk”。本版本不会替用户安装或修改桌面上的现有副本。

## 已知边界

- 快捷方式导入依赖 Windows Shell `IShellLink`。不可读取、损坏或目标不受支持的快捷方式会在导入结果中单独报告；具有特殊打包身份或无可解析路径的应用，可能仅能保留 `.lnk` 本身供 Shell 启动。
- 安全暖色过渡面是捕获失败时的回退显示，不是液态玻璃材质。系统策略、独占全屏或图形驱动可能阻止当前桌面采集；这类机器仍需实际体验确认回退行为。
- 旧启动项只有在值名冲突且内容精确匹配本产品约定、文件缺失而父目录存在时才可替换。指向其它安装副本的值不会解锁，需先由用户核实该副本。
- `LGDsk.exe` 是用户可见发布文件名，内部项目与程序集仍保留 GlassDesk 兼容身份。
