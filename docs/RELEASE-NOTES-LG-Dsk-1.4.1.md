# LG Dsk 1.4.1

1.4.1 是面向现有 GlassDesk 用户的安装迁移修正版。Dock、启动台、快捷键和液态玻璃渲染行为未作功能调整。

## 变更

- 新安装默认目录改为 `%LOCALAPPDATA%\Programs\LG Dsk`。
- 检测到旧版安装时，先核验产品登记、安装目录和 Inno Setup 卸载程序，再把 `Data` 目录逐文件复制到暂存目录并用 SHA-256 校验。
- 只有数据暂存校验完成后才静默卸载旧程序；随后把数据放入新目录。仅当当前用户 Run 项精确指向旧 `GlassDesk.exe --autostart` 时更新该路径。
- 迁移脚本不会主动删除旧安装目录里的 `Data` 副本；旧卸载器若保留非空用户目录，该副本可在确认新版本数据正常后由用户手动清理。
- 若旧程序仍在运行、路径/卸载程序无法核验、数据目录包含重解析点、目标已有用户数据，安装会中止以保护用户文件。
- 迁移使用阶段标记。旧程序已完全卸载后若安装中断，下次安装可从暂存目录恢复；若卸载状态不明确，安装会停止并保留暂存数据供人工核对。

## 安装包

- `LG-Dsk-1.4.1-win-x64-Setup.exe`：Windows 11 x64 用户级安装包。
- `LG-Dsk-1.4.1-win-x64.zip`：自包含便携版。
- `LG-Dsk-1.4.1-SHA256SUMS.txt`：发布资产校验清单。

安装前请从系统托盘完全退出旧 GlassDesk。迁移脚本记录位于 `%TEMP%\LG-Dsk-install-migration.log`。若安装中止，不要手动删除旧安装目录或迁移暂存目录。旧版安装器若在卸载阶段异常退出，新的安装器会保留暂存数据并停止；此时不要直接重复安装或清理目录。
