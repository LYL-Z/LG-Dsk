# LG Dsk 1.4.0

LG Dsk 1.4.0 是基于 GlassDesk 公开 1.3.1 源码快照制作的个人定制版。它保留原液态玻璃 Dock 与启动台，围绕桌面品牌、前台显示策略和应用切换做有限改动。

## 本版内容

- 产品名称和图标改为 LG Dsk。图标采用浮雕 LG 字标与少量陶土橙星芒，保留原液态玻璃风格。
- 普通应用处于前台时 Dock 收起，指针到达屏幕底边不会单独将 Dock 唤出；回到桌面后恢复显示。
- 新增 `Ctrl+Alt+Space` 运行应用切换条，支持在自动隐藏 Windows 任务栏时手动切换；全屏时避让。
- 启动台默认不自动聚焦搜索框；拖动应用到另一应用上停留约 500 ms 创建文件夹。
- 不包含自愿赞助入口；禁用上游自动更新，防止覆盖个人定制版本。
- 提供 x64 自包含便携 ZIP 与用户级安装程序。安装包可选择目录与创建桌面快捷方式；升级同一路径时保留已有 `Data`。

## 下载文件

- `LG-Dsk-1.4.0-win-x64-Setup.exe`：Windows x64 安装程序。
- `LG-Dsk-1.4.0-win-x64.zip`：自包含便携版，不包含个人 `Data`。
- `LG-Dsk-1.4.0-SHA256SUMS.txt`：上面两个下载文件的 SHA-256 校验值。

最低系统版本为 Windows 11 x64 Build 22000。便携版与安装版都自包含 .NET Runtime。运行前请退出托盘中的旧 GlassDesk 进程，以免单实例检测阻止启动。

## 来源与已知限制

上游公开源码止于 1.3.1；1.4.0 的公开说明称其基于 1.3.6 并含有未公开的 1.3.7 改动。因此，本版本按公开说明重建了有依据的行为，不是上游 1.4.0 源码的逐行合并。启动登录任务迁移、设置窗口空白区拖动和未公开的拖拽排序细节未移植。详见[移植记录](LG-Dsk-1.4.0.md)。

安装程序和应用未使用 Authenticode 证书签名，Windows 可能提示未知发布者。SHA-256 可检查下载完整性，但不能代替数字签名对发布者身份的验证。

Release 构建和安装包编译成功。Core、Dock 策略和 AppServices 聚焦测试通过；Dock 完整测试存在一项已在 v1.3.1 基线重现的窗口计数失败，AppServices 完整测试中与上游缺失打包脚本相关的 46 项失败。完整测试记录见[验证说明](LG-Dsk-1.4.0.md#验证记录)。尚未在联想拯救者 RTX 5090 设备上完成真实运行、240 Hz、HDR、多屏和游戏全屏验收。
