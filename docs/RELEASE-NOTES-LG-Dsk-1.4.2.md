# LG Dsk 1.4.2

1.4.2 是面向现有 LG Dsk/GlassDesk 用户的维护版本。它保留原有液态玻璃 Dock、启动台布局与主要交互，修正用户可见的 GlassDesk 名称残留、设置页风格/遮挡问题和桌面宠物残影，并补上全屏多应用查看与版本更新流程。

## 变更

- 发布安装包与便携包的主程序文件改为 `LGDsk.exe`。设置页和登录启动项显示此路径；升级时若产品目录内仍有旧 `GlassDesk.exe`，安装程序在新文件落盘后清理它。
- 保留既有安装 AppId、数据位置与内部托管程序集身份，避免重写历史升级注册、WPF 资源身份和用户数据。升级脚本同时识别旧 `GlassDesk.exe` 与新 `LGDsk.exe`，并仅改写精确匹配本产品的当前用户启动项。
- 设置窗改为不透明暖纸色面板，使用炭黑文字、陶土色强调和原创小型放射花形。配色参考用户指定的 Claude 视觉方向，图形为衍生创作，不复制 Anthropic 官方标志。Dock 与启动台仍保持原有液态玻璃。
- 设置窗显示时，Dock 自动收起；设置窗隐藏后按实际前台窗口状态恢复。原有运行应用切换快捷键仍由 Dock 处理。
- 玻璃背景采集在增强与公开 DWM 缩略图两条路径中都排除同时具备 layered、transparent、tool-window 扩展样式的浮层，避免把这类点击穿透宠物窗口的画面采样进 Dock 材质。
- Windows 任务栏开启自动隐藏且检测到外部程序全屏时，Dock 自动换成顶部紧凑应用岛，持续展示可切换窗口数与匹配到的后台进程数。点击应用岛可展开液态玻璃运行应用条；设置的全局快捷键也能直接展开，不依赖鼠标扫到屏幕边缘。
- 运行应用条显示可见和最小化的外部顶层窗口，点击窗口项即可尝试切换；另列出已导入应用库中按可执行路径匹配到的无窗口后台进程。后台项用于查看状态，不是可切换窗口；路径不可读取的系统/高权限进程不会显示。
- 新增 GitHub 正式版更新检查：设置中可手动检查，也可选择启动时检查并每 24 小时检查一次。下载前展示版本说明并要求用户确认；下载会校验 GitHub Releases API 提供的文件大小与 SHA-256。自动更新只支持已核验的安装版，便携版需手动安装；更新包仍未进行 Authenticode 签名。
- 从 1.4.1 更新到 1.4.2 时，原有 `Data` 不随文件名调整而移动；旧版迁移规则仍保留 SHA-256 逐文件校验、安装路径检查和暂存恢复保护。

## 安装资产

- `LG-Dsk-1.4.2-win-x64-Setup.exe`：Windows 11 x64 用户级安装包。
- `LG-Dsk-1.4.2-win-x64.zip`：自包含便携版，运行 `LGDsk.exe`。
- `SHA256SUMS.json`：包含安装包、便携 ZIP、清单和构建报告的 SHA-256 与文件长度。

每次发布都应生成独立的版本说明、安装包和 SHA-256 清单；本版本说明会随发布资产一同提供。

### 已知边界

- 宠物浮层修复通过窗口样式识别透明点击穿透工具窗；若特定宠物宿主不使用这组样式，其窗口不会命中该过滤条件，仍需要真实宿主复测。
- 应用岛只在外部程序被判定为全屏且 Windows 任务栏处于自动隐藏时自动出现。Windows 在任务栏自动隐藏时无法仅凭几何尺寸区分最大化窗口和真正全屏窗口；独占全屏也可能盖住桌面浮层。此时仍可尝试全局快捷键，或使用 Windows `Alt+Tab`。
- 运行应用列表涵盖 Windows 可枚举的顶层窗口；后台数量只统计应用库中可解析路径对应的无窗口进程，不是系统托盘图标的完整镜像。
- 自动更新服务读取本项目公开 GitHub 正式 Release。若网络策略阻断 GitHub，或目标 Release 缺少唯一、符合命名和 SHA-256 要求的 x64 安装资产，检查将失败；便携运行和未核验的安装目录不会自动覆盖。
- 设置窗采用自绘不透明颜色面板，减少桌面捕获与 DWM 材质切换造成的闪烁；其面板本身不使用液态玻璃材质。
- `LGDsk.exe` 是发布文件名，项目内部程序集、命名空间和历史 AppId 仍保留 GlassDesk 兼容标识。
